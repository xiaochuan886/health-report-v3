# 本地可执行包构建与分发

## 目标

让同事在未安装 Python 的电脑上直接运行报告生成应用。

## 产物说明

- Windows: `dist/HealthReportWeb/HealthReportWeb.exe`
- macOS/Linux: `dist/HealthReportWeb/HealthReportWeb`（当前机型用于验证流程）

应用已内置：

- 标准库：`report_pipeline/data/standard.xlsx`
- 健康指南与图片：`report_pipeline/data/health_guide*`
- 字体：`report_pipeline/fonts/*`
- logo 资源：`report_pipeline/logo.png` / `logo.svg`

## 构建

### Windows（生成 exe）

```bat
scripts\build_health_report_web.bat
```

说明：

- 脚本会自动创建 `.venv` 并安装依赖。
- 构建日志写入项目根目录：`build_health_report_web_windows.log`。
- 若双击运行失败不明，请打开该日志查看具体错误。

### macOS / Linux

```bash
./scripts/build_health_report_web.sh
```

## 同事使用

1. 双击运行 `HealthReportWeb.exe`。
2. 终端会显示本地地址：`http://127.0.0.1:8765`。
3. 浏览器打开该地址后上传：

- `lab.xls`（必填）
- `personal_info.xlsx`（可选）

4. 生成后下载 PDF。

## 注意

- 要生成 Windows `exe`，必须在 Windows 机器上执行构建脚本。
- 若端口 8765 被占用，可使用命令行参数：

```bat
HealthReportWeb.exe --port 8877
```

- 输出目录默认在当前运行目录的 `output/web-mvp/`。
