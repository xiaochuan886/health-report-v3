体重指数BMI：通常反映全⾝肥胖程度；我国成⼈体重指数BMI 的正常者应该注意保持在正常 范围（ $1 8 . 5 ~ \mathsf { k g / m } 2 \leqslant \mathsf { B M } \mathsf { \ k } 2 4 ~ \mathsf { k g / m } 2 )$ ）。超重和肥胖者应该尽量减⼩体重、争取达到正常范围， 并减少⾼⾎压、⾎脂异常、糖尿病等其他危险因素，综合降低⼼⾎管病⻛险。 

体脂储藏在腹部（腹内脂肪）⽐⽪下脂肪带来更⾼的⼼⾎管病⻛险，测量腰围是反映腹部脂 肪堆积的简便⽅法 。我国成⼈腰围的分类：正常范围男性 $< 8 5 ~ \mathsf { c m }$ ，⼥性 $< 8 0$ cm。当腰围85 cm≤男性 ${ < } 9 0$ cm、80 cm≤⼥性 ${ < } 8 5$ cm定义为中⼼性肥胖前期。当腰围男性 $\geqslant 9 0$ cm、⼥性 $\geqslant 8 5 \ \mathtt { c m }$ 定义为中⼼性肥胖。 

腰⾼⽐：正常范围在0.5以下。超过 正常值的说明已经有“⼤肚腩”了，腰⾼⽐数字越⾼说明“肚 腩”越⼤，是腹型肥胖的标志。2023年8⽉，美国华盛顿⼤学的研究⼈员在 Aging and Disease 上发表的⼀篇论⽂发现，腰⾼⽐越⼤，脑⼦萎缩越快，罹患痴呆⻛险更⾼。 

2010年美国⼼脏协会（AHA）提出了7项评估⼼⾎管健康（Cardiovascular Health, CVH）的重 要指标，包括4种健康⾏为（吸烟、体重指数、体⼒活动、膳⻝）和3种⽣理⽣化因素（⾎压、 总胆固醇、空腹⾎糖）指标。如果达到7种理想⼼⾎管健康（CVH）指标，能够减少62.1%的动 脉粥样硬化性⼼⾎管疾病 (ASCVD)发病（包括减少 $3 8 . 7 \%$ 的冠⼼病发病、减少 $6 6 . 4 \%$ 的脑卒中发 病）和 $6 0 . 5 \%$ 的ASCVD死亡。这7项CVH指标中，保持理想⾎压（收缩压/舒张压 $< 1 2 0 / 8 0 \ \mathrm { m m H } _ { 9 } )$ 带来的⼼⾎管健康获益最⼤：可以避免 $3 3 . 0 \%$ - 47.2%的动脉粥样硬化性⼼⾎管疾病ASCVD发病。 但我国⼈群满⾜4项及以上健康膳⻝标准的⽐例仅为 $4 . 2 \%$ 。因此强调保持理想⾎压 、健康膳⻝ 等⼼⾎管健康指标的⽬的是让⼼⾎管疾病防治关⼝前移，更⼤限度降低⼼脑⾎管疾病的发⽣， 拥有健康美好⽣活！

# 6、饮酒会增加患癌⻛险吗？

会！饮酒会增加⼈们患⼝腔癌、咽癌、喉癌、⻝管癌、肝癌、乳腺癌、结肠癌和直肠癌的⻛险。饮酒⼈⼠ 应该限制酒的摄⼊量，男⼠每天饮酒不宜超过2酒精单位，⼥⼠不超过1酒精单位。1酒精单位相当于360ml（1 美制液体盎司 ${ \approx } 3 0$ 毫升）啤酒、150ml的葡萄酒、或者45ml40度烈性酒。对某些癌症⽽⾔，同时饮酒并吸烟所 增加的患癌⻛险远⾼于只饮酒或只吸烟的⻛险。规律的饮酒，即便每周的饮酒量很少，也可增加⼥性患乳腺癌 的⻛险。乳腺癌⾼危⼥性群体可以考虑戒酒。 

# 7、膳⻝纤维能降低癌症⻛险吗？

能！膳⻝纤维是指多种⼈体不能消化的植物性碳⽔化合物。⼲燥⾖类、蔬菜、全⾕类和⽔果是膳⻝纤维的 优质来源。膳⻝纤维可进⼀步分为“可溶的”（⽐如燕⻨麸、豌⾖、⾖类和洋⻋前⼦纤维），和“不可溶的”（⽐ 如⼩⻨麸、⽔果⽪、坚果、种⼦和纤维素）。最新研究表明，膳⻝纤维可降低某些癌症的⻛险，尤其是结直肠 癌。因此，ACS建议⼈们⻝⽤全⾕类、蔬菜和⽔果等⾼纤维⻝物来帮助降低癌症⻛险。 

# 8、⼤⾖制品能降低癌症⻛险吗？

和其他⾖科植物⼀样，⼤⾖及⼤⾖制品是蛋⽩质的优质来源以及⾁类的有益替代品。⼤⾖含有多种植物化 学物质，其中包括异⻩酮。⼤⾖中的植物化学物质具有微弱的雌激素样活性，并可能有助于预防激素依赖性癌 症。有越来越多的证据表明⻝⽤传统⼤⾖制品⽐如⾖腐可能会降低⼈们患乳腺癌、前列腺癌或⼦宫内膜癌的⻛ 险。也有⼀些证据表明⻝⽤传统⼤⾖制品可能还会降低⼈们患某些其他癌症的⻛险。 

# 9、⼤蒜能降低癌症⻛险吗？

⼤蒜和其他葱属植物中含有的葱属植物化合物对健康有益的说法⼴为流传。针对⼤蒜能否降低癌症⻛险的 研究正在进⾏，⼀些研究表明⼤蒜可以降低结直肠癌的⻛险。⼤蒜和其他葱属植物可以被列⼊到能够降低癌症 ⻛险的推荐蔬菜⽬录当中。⽬前尚没有充⾜证据证明葱属植物化合物补充剂能降低癌症⻛险。 

# 10、肥胖会增加癌症⻛险吗？

会。超重或肥胖与⼈们更⾼的乳腺癌（绝经后⼥性）、结直肠癌、⼦宫内膜癌、⻝道癌、肾癌、胰腺癌、 胆囊癌（可能）患癌⻛险有关。肥胖也可能与⼈们更⾼的肝癌、宫颈癌、卵巢癌以及⾮霍奇⾦淋巴瘤、多发性 ⻣髓瘤和侵袭性前列腺癌的患癌⻛险有关。 

虽然对减肥是否会降低癌症⻛险的研究有限，但是⼀些研究表明，减肥会降低绝经后⼥性患乳腺癌和其他 癌症的⻛险。减肥具有的其他健康益处已得以证实，所以⼈们都⿎励超重⼈群减肥并保持健康体重。成年⼈避 免过度的体重增加也是⼗分重要的，因为这不仅可能会降低患癌⻛险，还可能会降低他们患其他慢性疾病的⻛ 险。

# 11、喝茶（红茶或绿茶）能降低癌症⻛险吗？

茶是⼀种饮料，茶树的叶⼦、嫩芽或细枝均可泡制成茶。红茶、绿茶、⽩茶、普洱茶和其他各种类型的茶 均来⾃于同⼀棵茶树，但是它们反映了不同的加⼯⽅式。⼀些研究⼈员提出，茶之所以会预防癌症是因为茶含 有抗氧化剂、多元酚和类⻩酮。动物研究已证明有些茶（包括绿茶）可降低癌症⻛险，但是⼈类研究发现的结 果喜忧参半。虽然实验室研究结果⼀直令⼈满意，⽽且喝茶也是许多美⻝的⼀部分，但是⽬前的证据尚不能证 明喝茶是降低癌症⻛险的主要原因。 

# 12、多吃抗癌⻝物就能防癌？

# 每天喝绿茶

北京⼤学医学院附属医院内科主任、外国医学杂志主编、美国医学会会员、保健专家、“中国健康万⾥⾏” 组委会科普专家⻬伯⼒教授综述国内外的研究成果，主张每⽇喝绿茶。有研究发现与那些从不喝绿茶的⼈相⽐， 每天喝绿茶⼀杯以上的⼈发⽣⼼梗的可能性减少 $42 \%$ 。 

⾸先，绿茶⾥含有氟可以杀菌。饭后3分钟，⽛⻮的菌斑就要出现，拿茶⽔漱⼝就把菌斑消灭了，⽽且坚 固⽛⻮。⼆是绿茶本⾝含茶⽢宁，茶⽢宁是提⾼⾎管韧性的，使⾎管不容易破裂。第三，绿茶中含有⾼⽔平的 ⻩酮类化合物，有很强的抗氧化作⽤，阻⽌低密度胆固醇被氧化成oxLDL，阻断形成动脉硬化斑的原料。这种 植物类化合物⼴泛存在于各种⽔果、蔬菜以及茶和红酒中，也有研究证实，摄⼊⻩酮类化合物较多的⼈能够降 低⼼梗的发病危险。 

出现⼼梗或脑梗的前驱不适征象，要⽴即嚼服300毫克阿司匹林，可起到抗凝⾎的作⽤。 

急性⼼梗是最适合诠释“时间就是⽣命”这个说法的急性病症。如果发病3⼩时内到医院的话，溶栓和介⼊ 治疗，在救命上没有差异，只要⾎管及时被疏通了都可以。
