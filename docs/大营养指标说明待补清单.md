## 1. 说明

当前标准文档 `指标说明` sheet 已补入：

- `CU(Q)` 铜

录入目标：

- `指标`：显示名
- `具体意义`：用于“临床表现”
- `临床应用`：用于“饮食补充 / 补充来源建议”

## 4. 录入格式约定

### 4.1 微量元素

- `具体意义`
  - 元素生理作用
  - 缺乏时常见表现
  - 必要时补充过量风险
- `临床应用`
  - 补充来源
  - 饮食建议
  - 必要时补充注意事项

### 4.2 维生素

- `具体意义`
  - 缺乏时常见临床表现
  - 过量时常见临床表现
- `临床应用`
  - 饮食补充
  - 常见食物来源
