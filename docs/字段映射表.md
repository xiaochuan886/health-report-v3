# 综合健康检测报告 v3.0 字段映射表

## 1. 说明

本表用于定义报告字段的来源、优先级、匹配规则和输出位置。

## 2. 全局来源优先级

### 2.1 数值相关字段

优先级：

1. 客户 `xls`

适用字段：

- 结果值
- 单位
- 参考值
- 采集时间
- 报告时间
- 项目编码

### 2.2 指标配置相关字段

优先级：

1. 标准文档 `指标明细`

适用字段：

- 指标简称
- 中文简称
- 性别规则
- 风险类别
- 排序
- 上海指标码

### 2.3 释义相关字段

优先级：

1. 标准文档 `指标对应风险部位`
2. 标准文档 `指标说明`
3. 标准文档 `癌症说明`

### 2.4 客户基础信息

优先级：

1. 客户基本信息 PDF

## 4. 指标主数据映射

| 目标字段 | 主来源 | 备用来源 | 规则 |
|---|---|---|---|
| 指标识别码 | `xls.项目代号` | `xls.项目编号` | 原始项目唯一识别值 |
| 指标简称 | `指标明细.指标简称` | 无 | 匹配成功后写入标准简称 |
| 上海指标码 | `指标明细.上海指标码` | 无 | 作为别称和二级匹配键 |
| 中文简称 | `指标明细.中文简称` | `xls.项目名称` | 优先使用标准中文简称 |
| 风险类别 | `指标明细.风险类别` | 无 | 癌筛 / 心筛 |
| 性别规则 | `指标明细.性别` | 无 | F / M / F/M |
| 排序 | `指标明细.排序` | 无 | 用于报告展示顺序 |

## 5. 指标匹配规则表

| 步骤 | 匹配左值 | 匹配右值 | 输出 |
|---|---|---|---|
| 1 | `xls.项目代号` 或 `xls.项目编号` | `指标明细.指标简称` | 命中则采用该指标配置 |
| 2 | `xls.项目代号` 或 `xls.项目编号` | `指标明细.上海指标码` | 第一步未命中时执行 |
| 3 | 未命中 | 无 | 标记为 `unmatched`，不进入主报告 |

建议输出匹配状态字段：

- `match_status`
- `match_key`
- `matched_indicator_short_name`

## 7. 检测结果字段映射

| 报告字段 | 来源 | 规则 | 输出位置 |
|---|---|---|---|
| 当前结果值 | `xls.项目测定值` | 旧版备用 `xls.结果`；原样保留，同时可转数值用于判定 | 各结果页、摘要页 |
| 单位 | `xls.单位` | 原样保留 | 结果表、说明页 |
| 参考值原文 | `xls.参考值` | 原样展示 | 结果表、摘要文案 |
| 结果提示 | `xls.高低标记` | 旧版备用 `xls.提示`；原始实验室标记，保留但不作为唯一判定依据 | 调试字段 |
| 接收时间 | `xls.接收时间` | 可选 | 质控页 |
| 采集时间 | `xls.采集时间` | 可选 | 质控页 |
| 报告时间 | `xls.报告日期` | 旧版备用 `xls.报告时间`；可选 | 质控页 |
| 标本类型 | `xls.样本种类` | 旧版备用 `xls.标本类型`；可选 | 质控页或附录 |
| 检验者 | `xls.检验医生` | 旧版备用 `xls.检验者`；可选 | 质控页 |
| 审核者 | `xls.审核医生` | 旧版备用 `xls.审核者`；可选 | 质控页 |

## 8. 参考值解析输出字段

| 解析字段 | 说明 |
|---|---|
| `ref_raw` | 原始参考值字符串 |
| `ref_kind` | `range / upper_bound / lower_bound / qual_threshold / qual_only / multi_rule / special` |
| `ref_low` | 下限数值 |
| `ref_high` | 上限数值 |
| `ref_op` | 比较符，如 `< > ≤ ≥` |
| `ref_label` | 定性标签，如 `阴性` |
| `ref_rule_text` | 多段规则原文 |

## 9. 风险判定输出字段

| 字段 | 说明 |
|---|---|
| `risk_status` | `normal / above / below / near_upper / near_lower / qualitative / reactive / suspicious / non_reactive / special` |
| `risk_message` | 用于报告展示的摘要文案 |
| `is_abnormal` | 是否突破标准区间 |
| `is_near_limit` | 是否接近临界值 |
| `limit_side` | `upper / lower / both / none` |

## 10. 第一部分结果小结

### 10.1 癌症健康监测小结

来源条件：

- 匹配成功
- 性别符合
- `风险类别 = 癌筛`

展示字段：

| 报告字段 | 来源 |
|---|---|
| 疾病类型 | `指标对应风险部位.疾病类型` |
| 异常指标摘要 | `xls.结果 + xls.参考值 + 风险判定结果` |
| 指标标签 | `指标对应风险部位.指标类型` |

### 10.2 心脑血管健康监测小结

来源条件：

- 匹配成功
- 性别符合
- `风险类别 = 心筛`

展示字段：

| 报告字段 | 来源 |
|---|---|
| 疾病类型 | 固定为心脑血管 |
| 异常指标摘要 | `xls.结果 + xls.参考值 + 风险判定结果` |

说明：

- 第一部分结果小结仅包含癌筛与心筛
- 微量元素与维生素不进入该摘要页

## 13. 第四部分大营养检测与建议

### 13.1 4-1 评估结果检测

来源条件：

- `风险类别 = 微量元素`
- `风险类别 = 维生素`

展示规则：

- 仅展示本次命中的白名单指标
- 按 `指标明细.排序` 排列
- 分为两个子区：
  - 微量元素检测结果
  - 维生素检测结果

| 报告字段 | 来源 |
|---|---|
| 指标名称 | `指标明细.中文简称`，无则 `xls.项目名称` |
| 参考值 | `xls.参考值` |
| 本次结果 | `xls.结果 + xls.单位` |
| 风险刻度条 | 根据 `xls.结果` 和 `xls.参考值` 计算 |
| 状态 | 风险判定结果 |

### 13.2 4-2 结果解读与建议

展示规则：

- 仅展示本次命中的白名单指标
- 说明与建议从结果页拆开，单独展示
- 结构参考心脑血管健康释义

| 报告字段 | 来源 |
|---|---|
| 项目 | `指标说明.指标`，无则 `指标明细.中文简称` |
| 临床表现 | `指标说明.具体意义` |
| 饮食补充 / 补充来源建议 | `指标说明.临床应用` |
| 风险类别子分组 | `指标明细.风险类别` |

## 15. 当前已确认不直接进入主板块的内容

以下内容当前默认不直接进入癌筛/心筛主板块：

- `xls` 中白名单外的额外指标
- 感染类项目
- 尿常规项目
- 普通血常规项目

说明：

- 这些内容仍可保留在原始数据层
- 如后续要生成“普通检查”板块，需要单独定义映射规则
