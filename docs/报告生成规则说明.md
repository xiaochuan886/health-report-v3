# 综合健康检测报告 v3.0 生成规则说明

## 1. 目标

本项目用于通过脚本生成客户《综合健康检测报告》PDF。

当前版本先统一数据规则与判定逻辑，不在本文件中约束最终页面视觉实现。

## 2. 数据源与职责

### 2.1 客户原始检测数据

来源：客户 `xls` 检测结果文件

职责：

- 提供指标结果值
- 提供参考值原文
- 提供单位
- 提供项目编号
- 提供采集/报告时间
- 作为所有数值判定的唯一来源

规则：

- 所有区间、阈值、阴阳性阈值均以 `xls` 中的 `参考值` 字段为准
- 不再使用标准库中的“指标及正常区间”参与结果判定

字段兼容说明：

- 历史客户 `xls` 可能存在旧版结构与新版结构两种表头
- 实现时必须先识别表头版本，再映射到统一中间字段

当前已确认的新版 `xls` 关键字段：

- `项目代号`
- `项目名称`
- `项目测定值`
- `高低标记`
- `参考值`
- `单位`
- `艾迪康条码`
- `样本种类`
- `接收时间`
- `报告日期`
- `审核时间`
- `采集时间`

当前已确认的旧版 `xls` 关键字段：

- `项目编号`
- `项目名称`
- `结果`
- `提示`
- `参考值`
- `单位`
- `条形码`
- `标本类型`
- `接收时间`
- `报告时间`
- `采集时间`

### 2.2 指标明细

来源：标准文档中的 `指标明细` sheet

职责：

- 定义报告白名单指标
- 定义展示顺序
- 定义性别适配规则
- 定义板块归属
- 定义指标简称与上海指标码

字段：

- `指标简称`
- `机构项目代码`
- `上海指标码`
- `中文简称`
- `性别`
- `风险类别`
- `排序`

规则：

- 是否纳入报告，以 `指标明细` 为准
- 板块归属以 `风险类别` 为准
- 展示顺序以 `排序` 为准
- 男女差异以 `性别` 为准

### 2.3 指标对应风险部位

来源：标准文档中的 `指标对应风险部位` sheet

职责：

- 为癌筛板块提供疾病类型映射
- 为肿瘤健康监测释义提供 `特异性 / 辅助` 字段

字段：

- `指标简称`
- `疾病类型`
- `指标类型`

### 2.4 指标说明 / 癌症说明

来源：标准文档中的 `指标说明`、`癌症说明` sheet

职责：

- 提供指标释义文案
- 提供癌种说明文案
- 提供健康管理建议

### 2.5 客户基本信息表

来源：客户基本信息 PDF

职责：

- 提供姓名、性别、年龄、出生日期等基础信息
- 提供体征信息，如身高、体重、BMI、血压、腰围
- 提供病史、既往史、家族史、生活习惯等信息

规则：

- 基础信息页以客户基本信息 PDF 为准
- 不从 `xls` 中回填客户基础信息

## 3. 指标匹配规则

客户 `xls` 中的项目编码字段与标准文档中的指标配置按以下顺序匹配：

1. 优先使用 `指标明细.指标简称` 匹配 `xls.项目代号` 或 `xls.项目编号`
2. 若未匹配，再使用 `指标明细.上海指标码` 匹配 `xls.项目代号` 或 `xls.项目编号`
3. 若仍未匹配，则视为未纳入本版报告指标

说明：

- `上海指标码` 视为 `指标简称` 的别称
- 未匹配到的指标保留在原始数据层，不进入报告主文

建议在实现中保留匹配来源标记：

- `exact_by_short_name`
- `fallback_by_shanghai_code`
- `unmatched`

## 4. 报告入选规则

一个原始检测项目进入报告，必须同时满足以下条件：

1. 能在 `指标明细` 中匹配到
2. 符合客户性别
3. 属于本版报告定义的展示板块

说明：

- 原始 `xls` 中存在但不在 `指标明细` 白名单中的项目，不进入癌筛/心筛主板块
- 额外项目未来如需展示，应单独定义新板块规则

## 5. 报告板块规则

### 5.0 V1 报告总结构

V1 版报告主结构固定为：

1. 基础信息
2. 质控页
3. 第一部分 评估结果小结
4. 第二部分 癌症健康监测与指导
5. 第三部分 心脑血管健康监测与指导
6. 第四部分 大营养检测与建议
7. 第五部分 医学名词释义或健康生活指南

V1 说明：

- 保留简化风险刻度条
- 去掉趋势图
- 白名单外项目不纳入报告
- 第一部分小结仅保留癌筛和心筛，不纳入大营养检测摘要

### 5.1 癌症健康监测

来源条件：

- `指标明细.风险类别 = 癌筛`

适用内容：

- 第一部分结果小结中的癌筛摘要
- 第二部分癌症健康监测与指导
- 肿瘤健康监测释义

### 5.2 心脑血管健康监测

来源条件：

- `指标明细.风险类别 = 心筛`

适用内容：

- 第一部分结果小结中的心筛摘要
- 第三部分心脑血管健康监测与指导

### 5.3 基础信息与普通检查

来源条件：

- 基础信息页从客户基本信息 PDF 提取
- 普通检查是否纳入本版实现，后续单独定义

### 5.4 大营养检测

来源条件：

- `指标明细.风险类别 = 微量元素`
- `指标明细.风险类别 = 维生素`

适用内容：

- 第四部分 大营养检测与建议

结构：

- `4-1 评估结果检测`
- `4-2 结果解读与建议`

规则：

- 大营养检测分为两个子类展示：
  - 微量元素检测
  - 维生素检测
- 仅展示“本次命中的白名单指标”
- 不展示未命中或未检测项目
- 不做趋势图
- 结果页保留简化风险刻度条

## 6. 参考值解析规则

所有结果判定均基于 `xls.参考值` 原文解析。

### 6.1 支持的参考值类型

#### A. 双边区间 `range`

示例：

- `0.00-5.00`
- `3.50-9.50`
- `1.003-1.030`

含义：

- 解析为 `low` 和 `high`

#### B. 单边上限 `upper_bound`

示例：

- `<12.00`
- `≤5.093`
- `<1.000E+02`

含义：

- 解析为上限阈值

#### C. 单边下限 `lower_bound`

示例：

- `>1.04`
- `>0.16`

含义：

- 解析为下限阈值

#### D. 定性阈值 `qual_threshold`

示例：

- `阴性：<0.05`
- `阴性：<1.00`
- `阴性：>1.00`

含义：

- 保留展示标签
- 判定仍按阈值和比较符执行

#### E. 纯定性 `qual_only`

示例：

- `阴性`
- `未见`
- `未检出`
- `/`

含义：

- 仅用于定性比对
- 不参与“接近临界”判断

#### F. 多段规则 `multi_rule`

示例：

- `＜8.00无反应性\n8.00-12.00可疑\n≥12.00有反应性`

含义：

- 表示分段结果判定
- 需要按分段区间输出状态

#### G. 特殊规则 `special`

示例：

- `<1:80`
- `透明管型0-1/LP、其它管型阴性`

含义：

- 无法完全通过通用规则稳定解析
- 需按项目编号单独特判

### 6.2 解析优先级

解析时按以下顺序执行：

1. `multi_rule`
2. `qual_threshold`
3. `range`
4. `single_bound`
5. `qual_only`
6. `special`

## 7. 风险判定规则

### 7.1 异常判定

#### `range`

- `value < low` => 低于标准区间
- `value > high` => 超过标准区间

#### `upper_bound`

- `value > bound` => 超过标准区间

#### `lower_bound`

- `value < bound` => 低于标准区间

#### `qual_threshold`

- 按比较符和阈值执行异常判定

#### `qual_only`

- 仅进行定性比对

#### `multi_rule`

- 按规则文本定义的分段标签执行结果归类

### 7.2 接近临界判定

#### `range`

- 接近上限：
  `value >= low + 0.8 * (high - low)`
- 接近下限：
  仅当 `low != 0` 时判定，
  `value <= low + 0.2 * (high - low)`

#### `upper_bound`

- 接近上限：
  `value >= 0.8 * bound`

#### `lower_bound`

- 接近下限：
  `value <= 1.2 * bound`

#### `qual_threshold`

- 当前版本不输出“接近临界”
- 仅输出是否达到阈值要求

#### `qual_only`

- 不输出“接近临界”

#### `multi_rule`

- 直接按规则分类，不额外输出“接近临界”

## 8. 结果文案规则

结果小结与风险预警的核心描述仅包含以下两类：

- 突破标准区间
- 接近临界值

对应文案模板：

- `超过标准区间`
- `低于标准区间`
- `接近上限`
- `接近下限`

展示时应同时带出：

- 指标名称
- 当前结果值
- 参考值原文

## 9. V1 结果摘要规则

### 9.1 第一部分 评估结果小结

V1 仅保留两个板块：

- 癌症健康监测小结
- 心脑血管健康监测小结

#### 癌症健康监测小结

规则：

- 按不同癌症疾病类型分类展示
- 每个癌种下汇总本次命中的异常或接近临界指标
- 仅展示两类信息：
  - 超出临界值、不在参考范围内
  - 接近临界值

#### 心脑血管健康监测小结

规则：

- 将所有心筛相关指标整合在一起展示
- 不按疾病类型拆分
- 仅展示两类信息：
  - 超出临界值、不在参考范围内
  - 接近临界值

### 9.2 大营养检测不进入第一部分摘要

V1 中：

- 微量元素
- 维生素

均不进入第一部分结果小结。

原因：

- 这两类更适合做指标级结果展示与说明建议
- 不适合与癌筛、心筛的疾病风险摘要混合展示

## 10. 第四部分 大营养检测与建议规则

### 10.1 4-1 评估结果检测

本节用于展示本次命中的微量元素和维生素检测结果。

展示规则：

- 按 `风险类别` 分为：
  - 微量元素检测结果
  - 维生素检测结果
- 按 `指标明细.排序` 展示
- 仅展示本次命中的白名单指标

每项展示字段：

- 指标名称
- 参考值
- 本次结果
- 简化风险刻度条
- 状态

状态文案沿用全局规则：

- 超过标准区间
- 低于标准区间
- 接近上限
- 接近下限
- 正常

### 10.2 4-2 结果解读与建议

本节用于展示大营养检测的说明与建议，结构参考心脑血管健康释义。

展示规则：

- 仅展示本次命中的白名单指标
- 不展示未命中项目
- 说明与建议从结果页拆开，单独展示

每项展示字段：

- 项目
- 临床表现
- 饮食补充 / 补充来源建议

字段映射：

- `指标说明.指标`：用于显示名
- `指标说明.具体意义`：用于“临床表现”
- `指标说明.临床应用`：用于“饮食补充 / 补充来源建议”

录入约定：

- 微量元素类：
  - `具体意义` 记录元素作用、缺乏/过量相关表现
  - `临床应用` 记录补充来源及建议
- 维生素类：
  - `具体意义` 记录缺乏/过量临床表现
  - `临床应用` 记录饮食补充建议

## 11. 项目级特判

当前已识别需要项目级特判的项目：

- `ANA_D`
  参考值格式：`<1:80`
- `ACA`
  参考值格式：三段式反应性规则
- `10529200`
  项目名称：`尿管型`
  参考值格式：`透明管型0-1/LP、其它管型阴性`

规则：

- 特判项目优先于通用参考值解析
- 特判逻辑需要在实现文档或代码中单独维护

## 12. 不再使用的旧规则

以下旧规则在 v3.0 中废止：

- 用标准库“指标及正常区间”直接判断客户结果
- 按原始 `xls` 全量项目直接进入报告
- 忽略性别差异直接展示固定指标

## 13. 后续实现要求

实现时至少需要输出以下中间结构：

- 指标匹配结果表
- 参考值解析结果表
- 风险判定结果表
- 报告板块数据集

这样可以保证：

- 结果可追踪
- 规则可调试
- 数据问题可回查
